## md2site とは

ディレクトリ（git リポジトリなど）内の markdown 群を、README を起点とした静的ドキュメントサイトに変換する単一バイナリの CLI です。このドキュメントサイト自体も md2site で生成・公開されています（ドッグフーディング）。
