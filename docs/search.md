# 検索の仕組み

md2site の検索は、外部サービスやサーバ側処理を使わない完全クライアントサイドの全文検索です。日本語と英語の両方で動作します。

## なぜ自作か

静的サイト向け検索の定番である lunr.js などは、空白でトークン分割する英語前提の設計のため、分かち書きのない日本語をほぼ検索できません。日本語対応には形態素解析かバイグラムが必要ですが、ドキュメントサイト規模（数百ページ程度）なら**正規化済みテキストへの部分一致検索**で十分な精度と速度が出ます。md2site はこの方式を採用し、トークナイザなしで日英両対応しています。

## インデックスの形式

ビルド時に各ページからプレーンテキスト（見出し・本文・コードブロック）を抽出し、`assets/search-index.js` に出力します。

```js
window.__MD2SITE_INDEX__ = {"pages": [
  {"t": "ページタイトル", "u": "docs/setup/index.html", "b": "本文テキスト..."}
]}
```

ポイントは JSON ファイルではなく **JavaScript ファイル**として出力し、`<script src>` で読み込むことです。`fetch()` で JSON を読む方式は `file://` で開いた場合に CORS で失敗しますが、`<script src>` は `file://` でも動作します。このため生成したサイトはサーバなしでブラウザに直接ドラッグしても検索が機能します。

本文はページあたり 20,000 文字でカットし、インデックスの肥大化を防いでいます。

## 検索処理（クライアント側）

`assets/app.js`（依存ライブラリなし、素の JavaScript）が検索ボックスの入力ごとに実行します。

1. クエリを小文字化し、空白で複数キーワードに分割
2. 各ページのタイトル+本文（小文字化済み）に対して**全キーワードが部分一致**するかを判定（AND 検索）
3. スコアリング: タイトル一致 +10、本文一致 +1
4. 上位 20 件を表示。最初にヒットした位置の前後を抜粋として切り出し、`<mark>` でハイライト

結果はサイドバーのナビと入れ替わりで表示され、Escape キーで検索を解除できます。

## 制約

- 部分一致のため、活用形やゆらぎ（「走る」と「走った」）は吸収しません
- インデックスは全ページ分を最初に読み込むため、数千ページ規模ではロードが重くなります。その規模では Pagefind 等の分割インデックス型の検索が適しています
